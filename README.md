# Prog Basics II Project
For my Programing Fundamentals 2 Finale, I’ve decided to take on the challenge of creating an AI-powered chatbot designated ARCEUS

## Features
This project focuses on the development of a learning-based AI Chatbot in Python. It uses a JSON knowledge base to recieve information from user input, and in turn answer whatever question a user asks.

For the moment, the questions are meant to be very basic and limited but I hope to update the code in the future to expand on searching for close matched words, sentences, phrases, etc. to help further the AI's learning base.

THIS CHATBOT DOES NOT REQUIRE PURCHASING OF ANY API KEYS. I know it's a hassle to creating an account or pay for a subscription to use something like an API key - this code is very simple and works on your computer without the need for one. Just make sure you have the latest version of Python or PyCharm (It's what I'm currently using) when you download the code file!

## Installation
Simply download from the GitHub Code Page, extract the file and open with PyCharm or Python!
